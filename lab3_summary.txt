Lab 3 Summary

What is SSH?
SSH stands for Secure Shell. It is a secure way to connect my computer to GitHub. SSH is useful because it allows me to securely send and receive files without entering my GitHub password every time.

What is a remote repository?
A remote repository is a copy of my Git repository stored online, for example on GitHub. It allows me to store my project online and access it from different computers.

What does git push do?
The `git push` command sends my local commits to the remote repository on GitHub. This updates the GitHub repository with the changes I made on my computer.
